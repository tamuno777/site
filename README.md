# Winnie Davis: One-Page Portfolio

Plain HTML/CSS/JS. No build step, no dependencies.

## Edit your content
Open `index.html` and change the `C = { ... }` block near the bottom (marked "EDIT YOUR CONTENT HERE").
- Add work links: put your URLs in `project.links` (empty url shows "Coming soon").
- Add LinkedIn/GitHub: fill the `socials` urls.
- Lead capture: create a free form at formspree.io and paste the URL into `formEndpoint`. Leave empty to open the visitor's email app instead.
- Colours: change `--brand` (burgundy) at the top of the `<style>` block.
